# Article output map

Main Tables 1–4, supplementary Tables S1–S5, and Figures S1–S2 are exported by `code/06_outputs_and_checks.py` after the statistical workflows have completed. Tables S6–S7 are generated by `code/07_composition.py`. Table captions and interpretive notes remain in the article and Online Resource 1; the CSV exports contain the tabulated cells.

Primary/scoped mine-cluster intervals and time summaries are estimated by `03_estimate_paths.py`. Independent inspection schedules are constructed by `04_followup_schedule.py`. Observation-definition sensitivities and paired classification contrasts are computed by `05_sensitivity.py`. Each table is generated from estimated results, not from a document or image.

`reference_outputs` provides the corresponding tables and figures for direct comparison. Reproduction tests do not read those formatted outputs during estimation. Numerical validation uses the separately listed unformatted reference CSVs only after calculations have completed.
